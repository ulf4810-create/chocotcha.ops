# チョコっちゃ‼フェスタ2027 運営ボード

運営で共有する、準備スケジュールの閲覧用サイトです。GitHub Pages で公開し、データ（タスク・書き込み・確認済み）は日髙さんの Google スプレッドシート「チョコっちゃ‼運営サイト_データ」に保存します。

- このリポジトリには画面のプログラムだけを置きます。タスクや書き込みの中身は置きません。
- **閲覧**：ログイン不要。URL を知っている人は誰でも見られます。書き込みはできません。
- **管理モード**：画面上部の「管理」から、日髙さんのパスワードでログインします。タスクの追加・編集（各タスクの「編集」ボタン）、メモの書き込み、「確認済みにして非表示」ができます。
- 管理用パスワードは、スプレッドシートの `members` タブで `role` が `admin` の行の `pass` 列にだけ保存します。ほかの行の `pass` は使いません。
- パスワードはブラウザに保存しません。ページを閉じる・再読み込みするとログアウトします。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` `style.css` `app.js` | サイト本体 |
| `config.js` | 書き込み先（Apps Script の URL） |
| `apps-script/Code.gs` | スプレッドシート側のプログラム（Apps Script に貼り付けて使う） |

## 初回の準備（日髙さん）

1. スプレッドシートの `members` タブで、日髙さんの行（`role` が `admin`）の `pass` 列に管理用パスワードを入力する。
2. スプレッドシートの「拡張機能」→「Apps Script」を開き、`apps-script/Code.gs` の中身を貼り付けて保存する。
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。次のユーザーとして実行：自分、アクセスできるユーザー：全員。
   コードを貼り替えたときは「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「バージョン：新バージョン」→「デプロイ」（URLは変わりません）。
4. 表示された URL（`…/exec`）を `config.js` の `api` に入れる。

## タスクの更新

タスクはスプレッドシートの `tasks` タブで管理します。行を書き換えるとサイトにそのまま反映されます。`id` は変えないでください（書き込みと確認済みの記録がこの id にひも付いています）。
